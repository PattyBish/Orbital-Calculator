# Orbital Period Calculator

A small Python script that calculates how long a satellite takes to orbit Earth,
based on its altitude. It uses Kepler's third law and assumes a circular orbit.

Built for CS3670 Lab 5 (Deliverable 1) by LT Patrick Bishop.

## How to run

    python3 orbit_calc.py

## Example output

    ISS (LEO): 420 km -> 93.0 minutes (1.55 hours)
    GPS (MEO): 20200 km -> 718.7 minutes (11.98 hours)
    Geostationary (GEO): 35786 km -> 1436.1 minutes (23.93 hours)

To try other orbits, edit the ORBITS list in orbit_calc.py.
